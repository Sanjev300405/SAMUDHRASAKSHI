# Live and historical data connections

## Available in this build

| Layer | Connection | What the dashboard does | Boundary |
| --- | --- | --- | --- |
| Incident reports | NOAA IncidentNews public CSV | Bundled searchable snapshot plus **Refresh NOAA** on demand | NOAA's `open_date` is usually the notification date; coordinates can be approximate. Not an image or trajectory input. |
| SAR scene discovery | Copernicus Data Space OData catalogue | Searches Sentinel-1 product metadata around a coordinate and date range | Metadata search only. Retrieve and process a product before interpreting it as a slick. |
| Current ocean/wind context | Open-Meteo Marine and Weather APIs | Fetches current model fields on demand for the selected incident coordinates | Present-day model estimate, not an in-situ observation and not historical forcing. The UI labels it accordingly. |

## Required for a real historical attribution run

The pipeline still needs a scene with its acquisition time and slick geometry, AIS tracks with timestamped fixes, and current/wind samples covering the same place and time. Import these through **Historical replay**. The importer records each source and refuses to invent missing tracks or forcing.

The live connectors above do not provide open global historical AIS. Add only AIS from an authorised archive/provider or data supplied for the case. No AIS track is generated by NOAA incident records or by the live weather buttons.

For current forecasts, Open-Meteo's Marine API reports model fields. Current direction is converted to east/north components; weather wind direction is treated as meteorological direction-from. Coastal grid accuracy is limited. The result is for contextual display only and is not passed into the historical hindcast.

## Local setup

No API key is needed for the NOAA CSV refresh, Sentinel-1 catalogue search, or Open-Meteo calls. The backend needs an internet connection. If a provider is unreachable, the bundled incident snapshot remains available. The browser app does not expose provider credentials because these connectors do not require user secrets.

## Responsible use

Incident catalogue entries and satellite catalogue results are leads for an analyst. A spatial/time match is not an oil-spill detection. Model output and vessel association scores are uncertain and are not legal findings. Preserve source URLs, timestamps, data-quality notes, and human review in exported reports.
